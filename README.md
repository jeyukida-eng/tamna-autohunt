# 오토헌트 · 탐나국 유랑기 v4 — 장비 180종 · 직업 스킬 20종

제육황제, 몽돌이, 소랑이, 소라대감, 반듯대왕이 탐나국을 모험하는 1인용 자동사냥 RPG입니다.
원본 이미지의 주요 특징을 참고한 실시간 3D 캐릭터 5종과 10개 지역을 제공합니다.
3D 모델은 게임용으로 간소화했으며 원본 이미지의 모든 세부 질감을 재현하지는 않습니다. 원본 이미지는 선택 화면과 3D 비지원 환경에서 사용합니다.

## 웹에서 바로 시작

[게임 시작하기](https://jeyukida-eng.github.io/tamna-autohunt/)

PC와 휴대폰에서 주소를 열고 캐릭터 선택 → 자동사냥 시작을 누르세요. 다음 접속에는 이어하기를 선택하세요.
휴대폰에서 즐겨찾기나 홈 화면에 추가하면 찾기 쉽습니다.
기존 다운로드 버전의 진행은 저장 파일 내보내기/불러오기로 옮길 수 있습니다.

## 바로 시작 (다운로드 버전)

1. ZIP 파일을 먼저 전부 압축 해제합니다.
2. 폴더 안의 **게임시작.html**을 더블클릭합니다. `index.html`을 열어도 동일합니다.
3. 캐릭터를 선택한 뒤 **자동사냥 시작**을 누르세요.
4. 다음에는 같은 파일을 열어 **이전 모험 이어하기**를 누르면 됩니다.

설치·로그인·빌드·인터넷 연결이 필요하지 않습니다. 최신 Edge, Chrome, Safari의 일반 창을 권장합니다.
ZIP 안에서 HTML만 열면 이미지와 코드가 연결되지 않습니다. 반드시 전체 압축을 먼저 해제하세요.

## 3D 캐릭터

- 사냥터와 아레나의 플레이어/라이벌은 실제 메시·관절·조명으로 렌더링하는 3D 모델입니다.
- 캐릭터의 이동 방향에 따른 회전, 팔다리 걷기, 공격, 대기, 소랑이 날갯짓을 적용했습니다.
- `캐릭터 돌려보기`에서 다섯 캐릭터를 선택하고 드래그·좌우 버튼·자동 회전으로 살펴볼 수 있습니다.
- 돌려보기 화면에서는 전투가 일시 정지합니다. 닫기 또는 Esc로 복귀하세요.
- WebGL 2가 필요합니다. 사용할 수 없거나 그래픽 컨텍스트를 잃으면 원본 이미지로 표시합니다.
- 라이브러리를 파일에 포함해 인터넷 없이 실행됩니다. CDN 접속이 없습니다.
- 전투 필드와 몬스터는 2D이며 캐릭터만 3D입니다.
- 이전 v2/v3의 저장 키와 읽기 호환을 유지해 같은 브라우저/경로의 저장이나 내보낸 저장 파일을 이어서 사용할 수 있습니다.

## 저장과 이동

- 5초마다, 처치·강화·아이템 사용·탭 이동 시 자동으로 저장합니다.
- `지금 저장` 버튼으로도 저장할 수 있습니다.
- 저장 위치는 현재 기기의 해당 브라우저입니다. 시크릿 창 종료·브라우저 데이터 삭제·파일 경로 변경 시 이어하기 데이터가 사라지거나 다른 저장 영역이 사용될 수 있습니다.
- `파일 내보내기`로 JSON을 보관하고 다른 기기에서 `파일 불러오기`를 이용하세요.
- 기존 v2/v3의 저장 파일은 자동으로 v4 형식으로 변환됩니다. 잘못된 파일은 거부하며 불러오기가 실패해도 현재 모험을 유지합니다.
- 브라우저가 기기 저장을 차단하면 안내가 표시됩니다. 이때 파일 내보내기로 보관할 수 있습니다.
- 게임 종료·다른 탭으로 이동·캐릭터 선택 화면에서는 전투가 멈춥니다. 오프라인 전투 보상은 없습니다.
- 자동사냥은 이어하기 후 직접 시작합니다.

## 조작

- 자동사냥: 가장 가까운 적을 찾아 이동·공격하고 스킬을 자동 사용합니다.
- 빈 바닥 클릭/터치: 자동사냥을 멈추고 해당 위치로 이동합니다.
- 몬스터 클릭/터치: 해당 적을 집중 공격합니다.
- 스킬 사용: 마나·재사용 시간·사거리 조건을 만족하면 직접 사용합니다.
- 자동사냥 중지: 이미 전투에 들어간 몬스터는 계속 공격합니다. 안전한 곳에서 쉬면 체력이 회복됩니다.
- 마나는 사냥 중에도 계속 회복됩니다.
- HP 30% 이하일 때 보유 물약을 자동 사용합니다. 가방에서 직접 사용할 수도 있습니다.
- 쓰러지면 3초 뒤 회복하며 부활합니다. 자동사냥은 직접 다시 시작하세요.

## 장비 · 도감 · 드롭

- 10개 지역 × 6개 부위 × 3개 특성 = 고유 이름/도감 ID를 가진 장비 180종.
- 부위: 무기, 갑옷, 투구, 신발, 반지, 부적.
- 장비마다 치명타, 스킬 위력, 흡혈, 회피, 체력, 마나, 마나 회복, 이동 속도 등의 추가 옵션이 적용됩니다.
- 일반/고급/희귀/영웅/전설 5등급. 등급별 능력치 배율은 1 / 1.5 / 2.2 / 3.1 / 4.2입니다.
- 일반 몬스터 기본 장비 드롭률 8%. 연속 35번째 처치까지 장비를 얻지 못하면 장비 1개를 보장합니다. 보정 때문에 장기 실제 획득률은 기본 8%보다 조금 높습니다.
- 일반 몬스터에게 장비가 나왔을 때 등급 비율: 일반 60%, 고급 29%, 희귀 9%, 영웅 1.8%, 전설 0.2%.
- 보스는 장비 1개 확정. 등급 비율: 희귀 73%, 영웅 25%, 전설 2%.
- 각 지역 일반 몬스터 12마리 처치 후 보스 도전 가능. 보스 처치 시 카운터가 초기화됩니다.
- 지역 등급에 따라 장비 능력치가 결정됩니다. 낮은 지역을 높은 캐릭터 레벨로 돌아도 고지역 장비가 나오지 않습니다.
- 추천 점수가 높은 장비는 자동 장착합니다. 체크를 끄면 모든 드롭을 가방에 보관합니다.
- 장비 가방 60칸. 직접 장착·판매 가능. 같은 종류/등급의 중복 장비는 골드로 교환하며, 가방이 가득 차면 추천 점수가 가장 낮은 장비를 자동 판매합니다.
- 도감에서 지역·부위·이름을 검색하고 발견한 종류를 확인할 수 있습니다. 발견 기록, 가방, 미획득 보정은 함께 저장됩니다.

## 장비 강화

**모든 강화 시도에는 선택한 장비 강화주문서 1장과 골드가 함께 필요합니다.** 골드만으로는 강화할 수 없습니다.

| 부위 | 안전 강화 한도 |
| --- | --- |
| 무기 | +6 |
| 갑옷·투구·신발 | +4 |
| 반지·부적 | +2 |

- 안전 한도 이내로 올라가는 시도는 성공률 100%입니다.
- 한도부터의 초과 강화 성공률은 순서대로 55%, 45%, 35%, 28%, 22%, 16%, 12%, 8%, 6%, 4%, 이후 3%입니다.
- 일반 주문서: 성공하면 +1. 위험 구간에서 실패하면 장비가 소멸합니다.
- 축복 주문서: 성공 시 +1(70%) / +2(25%) / +3(5%). 위험 구간 실패 시 장비 소멸. 골드 비용은 일반의 1.5배입니다.
- 보호 주문서: 성공 시 +1. 실패해도 장비와 단계 유지. 골드 비용은 일반의 2배입니다.
- 강화 한도 +20. 안전 구간에서 축복 주문서의 상승으로 안전 한도를 넘길 수 있습니다.
- 강화창에서 성공률, 소멸 확률, 주문서 보유량, 골드 비용을 확인합니다. 소멸 가능성이 있으면 확인란을 체크해야 실행됩니다.
- 강화창을 연 동안 전투는 멈춥니다. 실제 시도 때만 재료를 소모합니다.
- 보스는 일반 주문서 1장 확정, 축복 주문서 15%, 보호 주문서 8%를 별도 판정으로 추가 지급합니다.
- 일반 몬스터의 일반 주문서는 원래 드롭표가 있는 몬스터만 최대 2.5%, 축복은 0.3%, 보호는 0.1%입니다.

리니지M 공식 안내의 주문서 강화·실패 시 소멸·일부 주문서의 보존 구조를 참고한 **이 게임 자체 규칙과 확률**입니다. 리니지M의 실제 확률표를 복제한 것이 아닙니다. 출처와 설계 구분은 [강화 설계 참고](docs/enhancement-design.md)를 확인하세요.

## 직업 스킬과 효과

- 5직업 × 4스킬 = 20종. Lv.1 / 3 / 7 / 12에 차례로 해금합니다.
- 각 스킬은 별도의 마나 비용과 재사용 시간을 가집니다. 스킬별 자동 사용을 켜거나 끌 수 있습니다.
- 전투 화면 아래 단축 버튼 또는 키보드 1~4로 직접 사용합니다.
- 단일 공격, 광역 공격, 연쇄 공격, 회복, 보호막, 공격 속도 증가, 기절, 둔화, 끌어오기를 구현했습니다.
- 황금 참격, 유성, 번개, 얼음 파편, 꽃잎/연꽃 결계, 해일, 용의 궤적, 지진, 심판진 등 서로 다른 캔버스 효과를 사용합니다.
- 궁극기는 스킬명과 넓은 충격파를 표시하며 효과 수를 제한해 모바일 부하를 줄였습니다. 동작 줄이기 설정에서는 단순한 효과로 표시합니다.
- 스킬 해금, 선택, 마나, 쿨다운, 보호막은 실제 전투에 반영됩니다. 아레나 복귀 시 사냥터의 기존 상태를 보존합니다.

## 모의 아레나

- 실제 유저가 아닌 비슷한 레벨·장비 수준의 AI와 대련합니다.
- 대련은 완전 회복한 별도 상태로 시작하지만, 사냥터 복귀·저장에는 **입장 전 체력과 마나**를 적용합니다.
- 같은 아레나 탭을 다시 눌러 대련을 초기화할 수 없습니다.
- 대련 중 소모품·강화는 잠깁니다. 승리하면 명예 15, 골드 20 / 패배하면 명예 5를 얻습니다.
- 보상은 결과당 한 번 지급됩니다. 중도 이탈 시 결과 보상은 없습니다.

## 모바일과 웹 접속

화면은 320px 이상의 모바일 폭에 대응합니다. 휴대폰에서 ZIP 내부 파일을 바로 실행하기는 운영체제마다 다릅니다.
이 저장소는 GitHub Pages로 게임을 제공합니다. 다운로드 버전은 압축을 해제해 실행하고, 웹 버전은 배포된 게임 주소에서 바로 시작합니다.
별도 서버·계정·DB·멀티플레이·결제·앱 설치 기능은 포함하지 않습니다.

개발용 로컬 서버가 필요하면 Python 설치 후 폴더에서 실행하세요.

```sh
python -m http.server 8937 --bind 127.0.0.1
```

브라우저 주소: http://127.0.0.1:8937
서버를 이용한 주소와 파일을 직접 연 주소는 저장 영역이 서로 다릅니다.

## 구성

- 게임시작.html: index.html을 여는 시작 파일
- index.html: 게임 화면
- style.css: PC/모바일 디자인
- classes.js: 5개 캐릭터와 20개 직업 스킬
- items.js: 180종 도감, 등급/드롭/강화 규칙
- game.js: 전투·보스·화면·저장
- combat-fx.js: 직업별 파티클·충격파·광역 효과
- characters3d.js: 캐릭터 5종의 메시, 관절, 애니메이션, 3D 렌더러
- vendor/three.bundle.js: 오프라인용 Three.js 번들
- vendor/THREE-LICENSE.txt: Three.js MIT 라이선스
- assets/: 제공된 캐릭터 원본 이미지 5개
- CHANGELOG.md: 변경 내용과 검증 결과

## 개발 검증

게임 실행에는 Node나 npm이 필요하지 않습니다. 개발 시 회귀 검증을 수행하려면 Node 22 이상에서 `npm install` 후 `npm test`를 실행하세요. 장비 180종, 20스킬, 드롭 분포, 가방, 저장 호환, 강화 재료와 위험 판정 등을 검증하는 27개 테스트가 포함되어 있습니다.
