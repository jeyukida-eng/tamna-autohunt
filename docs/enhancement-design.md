# 강화 구조 참고 및 자체 설계

확인일: 2026-10-31

## 공식 참고 자료

- NC 리니지M 확률정보 — 무기 마법 주문서 강화 확률: https://probability.plaync.com/lineagem/view?probCategoryId=663af7390b56825a0765f23b
- NC 리니지M 확률정보 — 장신구 마법 주문서 강화 확률: https://probability.plaync.com/lineagem/view?probCategoryId=6656e17496b3cf5ad823b7af
- NC 구형 리니지M 가이드 — 인챈트 시스템: https://rc-wstatic.plaync.co.kr/lineagem/guidebook/game_item_enchant.html

공식 확률정보의 설명에서 일반 강화 실패 시 장비 소실, 장인의 무기 마법 주문서 실패 시 장비 보존 구조를 확인했습니다. 구형 가이드 검색 자료에는 일반 무기 +6, 일반 방어구 +4의 안전 구간이 설명되어 있습니다. 최신 게임의 모든 예외 장비/재질/이벤트 조건을 그대로 구현하지 않았습니다.

## 이 게임의 자체 설계

- 장비 전체에 공통으로 사용하는 강화주문서. 리니지M의 부위별 실제 주문서 구분과 다릅니다.
- 모든 시도에서 주문서 1장과 골드 필수.
- 안전 한도: 무기 +6, 방어구 +4, 반지·부적 +2.
- 초과 강화 성공률은 자체 설정. 리니지M의 실제 확률과 같다고 표시하지 않습니다.
- 일반/축복 주문서는 초과 강화 실패 시 장비 소멸. 보호 주문서는 실패 시 단계 유지.
- 성공률·소멸률·비용을 강화창에 표시. 소멸 위험 확인 전에는 시도 불가.
- 실제 현금 결제, 유료 주문서 판매, 거래소 또는 유료 확률 상품 없음.

이 문서는 게임 규칙과 출처를 구분하기 위한 기록입니다.
